# Keyboard shortcuts

These are Clanky's window controls, not shortcuts supplied by your shell. The
palette controls apply while the palette or its prompt is open.

| Key | Action |
| --- | --- |
| `Ctrl+Shift+P` | Toggle command palette |
| `Ctrl+Shift+B` | Show or hide sidebar |
| `Ctrl+Shift+T` | Open a tab |
| `Ctrl+Shift+D` | Split right |
| `Ctrl+Shift+E` | Split below |
| `Ctrl+Shift+W` | Close focused pane; closing the last session stops the server |
| `Ctrl+Shift+A` | Toggle agent permission for the focused terminal |
| `Ctrl+=` | Increase font size |
| `Ctrl++` | Increase font size |
| `Ctrl+-` | Decrease font size |
| `Ctrl+0` | Reset zoom |
| `Ctrl+Tab` | Next tab group |
| `Palette:Escape` | Close palette or prompt |
| `Palette:ArrowUp` | Previous action |
| `Palette:ArrowDown` | Next action |
| `Palette:Enter` | Run action or confirm prompt |
| `Palette:Backspace` | Remove a character from a prompt |

The terminal also forwards regular input and terminal keys to programs. See
[getting started](getting-started.md).
